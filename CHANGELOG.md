# Changelog

## 2.2.0

- Добавлено мобильное приложение .NET MAUI для Android и iPhone.
- Добавлен стартовый сигнал `Ж Ж Ж` с паузой перед каждой серией групп.
- Добавлены именованные профили скорости, тона, громкости, пауз, количества групп и выбранных символов.
- Системный голос Windows заменён встроенным естественным русским голосом, работающим без интернета.
- Исправлены напевы `Й`, `К`, `Ц` и `Ь` по учебному варианту пользователя.
- Добавлена автоматическая сборка Android APK и проверка iPhone-версии на симуляторе.
- Мобильный проект переведён на .NET 10 (`net10.0-android`, `net10.0-ios`), Android min 24; APK прикладывается к каждому релизу на GitHub.

## 2.1.4

- Удалён несовместимый параметр сжатия из framework-dependent single-file сборки.
- Добавлена статическая проверка параметров локальной публикации EXE.

## 2.1.3

- Локальная сборка EXE больше не скачивает крупные self-contained пакеты из NuGet.
- `BUILD-EXE.cmd` создаёт компактный единый EXE, использующий установленную среду .NET 8.
- Полностью автономная сборка без .NET по-прежнему создаётся автоматически в GitHub Actions.

## 2.1.2

- Исправлено аварийное завершение при первоначальном создании ползунков WPF.
- Сохранение настроек больше не запускается для неполностью созданного окна.
- Добавлена сборка автономного `MorseTrainer.exe` одним запуском `BUILD-EXE.cmd`.

## 2.1.1

- Исправлен запуск через `START-MORSE-TRAINER.cmd`: окно диагностики больше не закрывается автоматически.
- Вывод запуска сохраняется в `morse-start.log`, чтобы ошибку можно было сразу отправить разработчику.

## 2.1.0

- Добавлены системная, тёмная и светлая темы.
- Добавлен визуальный выбор произвольного набора букв, цифр и знаков.
- Паузы между символами и между группами настраиваются отдельно.
- Добавлена вкладка «Обучение» с карточками русских и латинских букв и цифр.
- Добавлены словесные напевы с синхронной подсветкой слогов.
- Добавлен вариант с произношением напева системным голосом Windows.
- Добавлены проверочные задания на слух и сохранение результата.

## 2.0.1

- Добавлены явные ссылки на `System.IO` для стабильной сборки WPF-проекта.
- Символьные константы переведены в Unicode escape-последовательности.

## 2.0.0

- Новый нативный интерфейс Windows на WPF.
- Русский и латинский алфавиты, цифры и пунктуация.
- Генератор групп и тренировка выбранных символов.
- Ввод ответа, автоматическая проверка и статистика ошибок.
- Настройка скорости, тона, громкости и пауз.
- Экспорт TXT и WAV.
- Сохранение последних настроек.
- Переносная сборка, установщик и автоматизация GitHub Releases.
