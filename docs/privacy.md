# Политика конфиденциальности Morse Trainer

Morse Trainer — бесплатное приложение для изучения азбуки Морзе (Android, iPhone, Windows). Приложение не требует регистрации, не показывает рекламу, не содержит аналитики и счётчиков и не передаёт ваши данные ни разработчику, ни третьим лицам.

## Какие данные хранятся и где

Все данные хранятся только на вашем устройстве:

- настройки тренировки и история занятий;
- свои напевы и записи своего голоса, если вы их сделали;
- файл отчёта о сбое, если приложение закрылось с ошибкой.

При удалении приложения эти данные удаляются вместе с ним.

## Разрешения

- **Микрофон** — только когда вы сами записываете свой голос для напева («Обучение» → «Свой голос…» или «✎» на карточке). Запись сохраняется на устройстве и никуда не отправляется.
- **Уведомления** — для ежедневного напоминания о тренировке, если вы включили его в «Настройках». Напоминание создаётся на самом устройстве.
- **Запуск после перезагрузки** — чтобы напоминание не пропало после перезагрузки телефона.
- **Вибрация** — чтобы напоминание могло вибрировать.
- **Интернет** — только когда вы нажимаете «Проверить обновления» (на Windows — «Обновления»): приложение запрашивает номер последней версии на GitHub, а если вы согласитесь обновиться, скачивает оттуда новую версию. GitHub при этом видит ваш IP-адрес, как при открытии любой веб-страницы. В версии из RuStore этой кнопки нет — обновления приходят через RuStore, и приложение в интернет не обращается.

## Передача данных

Приложение ничего не отправляет само. Настройки, записи голоса или отчёт о сбое уходят с устройства, только если вы сами нажмёте «Поделиться» или «Отправить отчёт» и выберете, куда их отправить.

## Дети

Приложение не собирает никаких данных и подходит для любого возраста.
