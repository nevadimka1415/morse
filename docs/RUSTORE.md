# Публикация в RuStore и автообновления на Android

Сейчас приложение ставится с GitHub Releases вручную: пользователь сам качает новый APK.
Есть два пути, чтобы обновления приходили сами.

## Вариант 1. Obtainium (без магазина, 5 минут)

[Obtainium](https://github.com/ImranR98/Obtainium) — бесплатное приложение, которое следит за
релизами на GitHub и само ставит обновления. Подходит для себя и для небольшого круга людей.

1. Установить Obtainium (APK с его страницы релизов на GitHub).
2. В Obtainium: «Добавить приложение» → вставить `https://github.com/nevadimka1415/morse`.
3. Obtainium найдёт `MorseTrainer-Android.apk` в последнем релизе, установит и дальше будет
   предлагать обновления при каждом новом теге `v*`.

Ключ подписи у нас постоянный, поэтому обновления ставятся поверх без удаления.

## Вариант 2. RuStore (магазин, публичное распространение)

RuStore — российский магазин приложений, предустановлен на большинстве Android в РФ,
публикация бесплатных приложений бесплатна. Обновления приходят пользователям автоматически.

Что понадобится (уточнить актуальные требования в [RuStore Console](https://console.rustore.ru)):

- аккаунт разработчика в RuStore Console (вход через VK ID; для физлица достаточно
  подтверждённого аккаунта, для платных приложений нужен статус ИП/юрлица);
- подписанный `MorseTrainer-Android.apk` из релиза GitHub (RuStore принимает APK, AAB не обязателен);
- название пакета `ru.morsetrainer.app` — оно должно оставаться неизменным между версиями;
- иконка 512×512 PNG, минимум 2 скриншота с телефона, короткое и полное описание, категория
  («Образование»), возрастной рейтинг (0+);
- ссылка на политику конфиденциальности: приложение не собирает данные и не выходит в интернет,
  об этом достаточно одной страницы, например в `docs/` этого репозитория, опубликованной через
  GitHub Pages;
- каждая новая версия должна иметь больший `versionCode` — у нас он считается из тега
  (`v2.2.1` → 20201), так что достаточно выпускать релизы по порядку.

Порядок: создать приложение в консоли → заполнить карточку → загрузить APK → отправить на
модерацию (обычно 1–3 дня) → после одобрения приложение появится в поиске RuStore.
Для следующих версий: загрузить новый APK из релиза GitHub и снова отправить на модерацию.

Ключ подписи (`X:\MorseTrainer\подпись-APK`, секреты репозитория) менять нельзя: RuStore, как и
Android, примет обновление только с той же подписью.
