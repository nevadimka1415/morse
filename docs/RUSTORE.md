# Публикация в RuStore

RuStore — российский магазин приложений для Android, на большинстве телефонов в России он уже стоит. Из магазина
приложение ставится в одно нажатие, без «неизвестных источников», и обновляется само. Публикация бесплатного
приложения бесплатна, публиковать можно как физическое лицо.

## Что уже готово

- **APK для RuStore** — `MorseTrainer-Android-RuStore.apk` в каждом релизе. Он отличается от обычного одним: в
  «Настройках» нет кнопки «Проверить обновления», вместо неё — «Обновления приходят через RuStore». Так требуют правила
  RuStore: приложение, скачанное из магазина, обновляется только через магазин. Подпись и номер версии те же, что у
  обычного APK, поэтому кто поставил приложение с GitHub, сможет обновиться из RuStore, и наоборот.
  Дымовой тест на эмуляторе проверяет этот APK в каждой сборке.
- **Политика конфиденциальности** — [docs/privacy.md](privacy.md), ссылка для карточки:
  <https://github.com/nevadimka1415/morse/blob/main/docs/privacy.md>
- **Иконка 512×512 и скриншоты 9:16** без строки состояния и кнопок Android — делает
  `scripts/rustore-assets.py` из снимков дымового теста (см. ниже). Готовый набор для 2.9.1 лежит в
  `X:\MorseTrainer\RuStore\`.
- **Тексты карточки** — ниже, их можно копировать как есть.

## Первая публикация (делает владелец аккаунта)

1. Войти в [RuStore Консоль](https://console.rustore.ru) через VK ID, тип аккаунта — «Физическое лицо».
   Регистрация мгновенная и бесплатная; паспорт спрашивают только при подключении продаж, а продаж нет.
2. «Создать приложение» → загрузить `MorseTrainer-Android-RuStore.apk` из последнего релиза.
   Название пакета `ru.morsetrainer.app` определится из APK — оно не меняется никогда.
3. Заполнить карточку текстами из раздела «Карточка», загрузить иконку и скриншоты.
4. В блоке «Чувствительные разрешения» вставить обоснования из раздела «Разрешения».
5. В «Комментарии для модератора» — текст из раздела ниже.
6. Отправить на модерацию. После одобрения приложение появится в поиске RuStore.

## Каждая новая версия

После каждого релиза на GitHub: RuStore Консоль → приложение → «Новая версия» → загрузить
`MorseTrainer-Android-RuStore.apk` этого релиза → в «Что нового» вставить раздел версии из [CHANGELOG.md](../CHANGELOG.md)
→ отправить на модерацию. RuStore может снять приложение, если его версия ниже, чем в других магазинах, поэтому
лучше не пропускать версии. Позже загрузку можно автоматизировать через API RuStore (нужен ключ из консоли).

## Карточка

**Название** (должно совпадать с названием на телефоне):

```
Morse Trainer
```

**Краткое описание** (без эмодзи, до 80 знаков):

```
Тренажёр азбуки Морзе: курс с нуля до 60 знаков в минуту, без интернета
```

**Категория:** Образование. **Возраст:** 0+. **Тип:** бесплатное.

**Подробное описание** (без эмодзи, заглавных букв и ссылок на другие магазины — это правила RuStore):

```
Morse Trainer — бесплатный тренажёр азбуки Морзе для приёма на слух. Подойдёт радиолюбителям, связистам и всем, кто хочет выучить морзянку с нуля. В приложении нет рекламы и регистрации, оно работает без интернета.

Курс «С нуля до 60 знаков в минуту». 14 шагов по методу Коха: каждый знак с первого дня звучит на рабочей скорости, новые знаки добавляются по четыре. Перед курсом открывается короткая книжка о том, как устроено обучение и почему метод Коха работает, — её можно пролистать или пропустить. Кнопка шага сама ставит нужные знаки, скорость и паузы, в конце курса — экзамен.

Тренировка на бумаге. Приложение передаёт случайные группы букв и цифр, вы записываете услышанное и сверяете с текстом задания. Во время прослушивания видно, какая группа звучит, — на бумаге не собьётесь. При желании ответ можно ввести и получить точность и разбор ошибок. Скорость от 20 до 300 знаков в минуту, растянутые паузы по Фарнсворту, настройка тона и громкости, помехи эфира: шум, замирания и дрейф тона.

Проверка на слух. Звучит знак — выберите его из четырёх похожих на слух вариантов. Знаки, в которых вы ошибаетесь, звучат чаще.

Обучение. Карточки русских и латинских букв и цифр с напевами («А — ай-даа») и подсветкой ритма. Напевы звучат живым голосом, а свой голос можно записать прямо в приложении.

Передача. Кнопка-ключ превращает нажатия в точки и тире и сразу расшифровывает их; разбор показывает, насколько ровно вы передаёте. Есть настоящий ключ или рация? Поднесите телефон к динамику — приложение само найдёт тон и скорость и расшифрует морзянку.

Второй курс «С 60 до 100 знаков в минуту» и учебный радиообмен — связь, как в эфире: CQ, оценка сигнала, имя, город, 73.

А ещё: ежедневное напоминание о тренировке, тёмная и светлая темы, русский и английский интерфейс.

Разрешения: микрофон — только по вашей команде: для записи своего голоса и для расшифровки морзянки с ключа или рации; уведомления — для напоминания о тренировке. Все данные остаются на телефоне и никуда не передаются.
```

**Скриншоты** (9:16, в таком порядке): тренировка, книжка курса, обучение, проверка на слух, передача, настройки.

## Разрешения

Приложение запрашивает только эти разрешения:

| Разрешение | Обоснование для консоли |
|---|---|
| `android.permission.RECORD_AUDIO` | 1) Запись своего голоса для напевов на карточках «Обучения»: начинается только по нажатию «Записать», хранится на устройстве и никуда не передаётся. 2) «Приём с микрофона» на вкладке «Передача»: по нажатию «Слушать микрофон» приложение расшифровывает азбуку Морзе с настоящего ключа или рации; звук обрабатывается на устройстве, не сохраняется и не передаётся. |
| `android.permission.POST_NOTIFICATIONS` | Ежедневное напоминание о тренировке в выбранное время; включается самим пользователем в «Настройках». |
| `android.permission.RECEIVE_BOOT_COMPLETED` | Восстановить напоминание о тренировке после перезагрузки телефона. |
| `android.permission.VIBRATE` | Вибрация напоминания. |
| `android.permission.INTERNET` | В версии для RuStore не используется: своей проверки обновлений в ней нет. |

Если консоль покажет `android.permission.DUMP` — это не запрос разрешения, а защита служебного компонента AndroidX
(`ProfileInstallReceiver`), она есть в любом приложении на AndroidX.

## Комментарий для модератора

```
Приложение работает без регистрации и без интернета. Курс: вкладка «Обучение» → «Начать курс» — сначала откроется книжка о курсе (её можно пролистать или пропустить), затем «Тренировка» с первым заданием. Проверка на слух — вкладка «На слух». Запись своего голоса — «Обучение» → «Свой голос…» (при первой записи приложение спросит доступ к микрофону). Расшифровка морзянки с микрофона — вкладка «Передача» → «● Слушать микрофон».
```

## Скриншоты и иконка заново

Когда интерфейс поменяется:

1. Скачать снимки последней зелёной сборки: `gh run download <id> -n MorseTrainer-Screenshots-Android -D shots`
   (Actions → Build mobile apps → артефакт `MorseTrainer-Screenshots-Android`).
2. `python3 scripts/rustore-assets.py shots rustore` — в папке `rustore` появятся `icon-512.png` (из тех же слоёв,
   что иконка на телефоне) и скриншоты `1-training.png` … `6-settings.png`.

## Важно на 2027 год: проверка разработчиков у Google

Google вводит обязательную проверку личности разработчиков Android: с 30 сентября 2026 — в Бразилии, Индонезии,
Сингапуре и Таиланде, в 2027 году — в остальных странах. Она работает на уровне самого Android и касается любого APK
(из RuStore, с GitHub): без неё новые установки и обновления на сертифицированных телефонах перестанут ставиться. Нужно
будет зарегистрироваться в Android Developer Console (это не Google Play), подтвердить личность и зарегистрировать
`ru.morsetrainer.app` с нашим ключом подписи. RuStore отдельно ничего не требует. Подробнее — в
[блоге RuStore](https://www.rustore.ru/developer/blog/google-menyaet-pravila-ustanovki-android-prilozhenij-chto-eto-znachit-dlya-razrabotchikov-rustore).

## Без магазина: Obtainium

[Obtainium](https://github.com/ImranR98/Obtainium) следит за релизами на GitHub и сам ставит обновления — подходит
для себя и небольшого круга людей:

1. Установить Obtainium (APK с его страницы релизов на GitHub).
2. «Добавить приложение» → вставить `https://github.com/nevadimka1415/morse`.
3. Obtainium найдёт APK в последнем релизе и дальше будет предлагать обновления при каждом новом теге `v*`.

Ключ подписи (`X:\MorseTrainer\подпись-APK`, секреты репозитория) менять нельзя: и Android, и RuStore примут
обновление только с той же подписью.
